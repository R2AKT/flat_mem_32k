# flat_mem_32k
<img src="flat_memory_32k_top.png">
32k flat (linear) memory board: 8k ROM + 8k EEPROM/RAM + 8k EEPROM/RAM + 8k RAM.
For Mega-80 (Mega-580) DIY 8-bit micro-computer - https://github.com/R2AKT/Mega-80.

ROM - 8k;
PROM - 8/16k;
RAM - 16/8k.

Status: not tested!

Плата плоской (линейной) памяти на 8к.
Для самодельной 8-битной микро-ЭВМ - https://github.com/R2AKT/Mega-80.

ПЗУ - 8кб;
ППЗУ - 8/16кб;
ОЗУ - 16/8кб.

Статус: не проверено!
